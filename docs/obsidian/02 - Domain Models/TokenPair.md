# TokenPair

Value object containing access and refresh JWT tokens.

## Fields

| Field | Type | Description |
|-------|------|-------------|
| `accessToken` | String | JWT access token (short-lived) |
| `refreshToken` | String | JWT refresh token (long-lived) |

## Token Configuration

| Parameter | Access Token | Refresh Token |
|-----------|-------------|---------------|
| Expiry | 15 minutes | 7 days |
| Contains | userId, roles, email | userId, tokenId |
